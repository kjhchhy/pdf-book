### 기능 (main.py / app.js)
- **순서 변경 버그 수정** — 기존 `/reorder`는 파일명을 임시 이름으로 바꿨다 되돌려서 실제로 아무것도 바뀌지 않았음.
  이제 `uploads/_order.json`에 순서를 저장하고, `/files`·`/preview`·`/build` 모두 그 순서를 사용.
- **썸네일 엔드포인트 추가** `/thumb/{name}` — 420px JPEG, `Cache-Control: max-age=3600`, 메모리 캐시.
  기존엔 `/preview`가 전 페이지를 base64 한 덩어리로 내려서 페이지가 많으면 느렸음.
- 이미지 확장자만 취급(`IMAGE_EXT`) — `_order.json` 같은 파일이 목록에 섞이지 않음
- 업로드 시 순서 목록에 자동 추가, 삭제·전체삭제 시 목록에서 제거
- PDF 다운로드 파일명을 책 제목으로
- 빌드 중 버튼 비활성 + 스피너

## 추가 기능 — 페이지 크기 임의 설정 (사용자 지정) · 2026-10-25

사용자 요청: "페이지 크기 임의설정도 추가해줘" + "그 비율은 첫페이지 크기를 기준으로 하면 될거 같아"

### UI (`app/templates/index.html`, `app/static/app.js`, `app/static/style.css`)

- 페이지 크기 분절 버튼에 **`사용자 지정`(CUSTOM)** 추가 → 선택하면 가로/세로(mm) 입력 패널이 열림
- **`세로는 첫 페이지 비율로 자동 계산`** 체크박스(기본 켜짐)
  - 켜짐: 가로만 입력 → 세로 = 가로 × (첫 페이지 이미지 세로/가로). 세로 칸은 읽기 전용으로 회색 표시
  - 꺼짐: 세로를 직접 입력
- 비율 문구: `가로 210 × 세로 297 mm · 비율 70:99 (첫 페이지 기준)`
- 버그 수정: `.custom-size` 가 `.seg` 의 **형제**라서 `seg.querySelector()` 가 null 이었음 →
  `seg.parentElement.querySelector()` 로 변경. (그래서 처음엔 "사용자 지정"을 눌러도 패널이 안 열렸다)

### 서버 (`app/main.py` `/build`)

- Form 파라미터 `custom_w`, `custom_h`, `custom_auto` 추가
- `page_size == "CUSTOM"`: `custom_w` 필수(없으면 400). `custom_auto == "true"` 또는 `custom_h <= 0` 이면
  **첫 이미지 실측 픽셀 비율**로 `base_h = custom_w × (fh/fw)` 계산 (여백 자르기 옵션과 동일한 전처리 사용)
- `@page { size: {base_w}mm {base_h}mm }` 로 그대로 적용

### 검증 (실측)

- 1200×1600 테스트 이미지 업로드 → CUSTOM 선택 → 패널 열림(hidden=false), 자동 세로 `297` (첫 사진 297×420 기준)
- 가로 100 입력 → 세로 **141.4** 자동, 자동 해제 후 세로 직접 입력(`1:2`) 정상

## 레이아웃 개편 — 설정은 위로, 좌측 세로 미리보기 · 2026-10-25

사용자 요청: "설정하는건 위쪽으로 올려주고, 좌측에 세로로 미리보기 해주고, 지금 올려진 작업부분에서 선택한 1페이지를 미리보기로 띄워줘"

### 바뀐 구조

- **상단 가로 설정 바** (`.settings` / `.settings-body`): 책 제목 · 페이지 크기 · 이미지 맞춤 · 토글 2개 · 버튼 3개(PDF 만들기/이미지 추가/전체 삭제)를 한 줄에 배치, 좁으면 자동 줄바꿈
- **좌측 세로 미리보기** (`.stage`): `position: sticky; top: 16px`, 프레임 높이 `min(58vh, 470px)`
  - 페이지 카드를 누르면 그 페이지가 크게 뜨고, 카드에 `is-active` 강조(번호 배지가 accent 색)
  - 상단 `03 / 259` 표시, 하단 `‹ 파일명 ›` 이전/다음 버튼, 키보드 ←/→ 도 동작
  - 선택은 `localStorage.pdfbook_selected` 에 저장 → 새로고침해도 유지, 삭제된 경우 첫 페이지로
- **우측 페이지 목록**: 기존 그리드 유지 (선택용)
- 모바일(≤980px): 설정 → 미리보기 → 목록 순으로 세로 스택, 하단 고정 액션바 유지

### 세로 1줄 목록 + 큰 미리보기 (같은 날 두 번째 정정)

사용자: "페이지 그 선택하는걸 세로로 1줄로 쭉 세우고.. 옆에 미리보기를 크게하라고"
